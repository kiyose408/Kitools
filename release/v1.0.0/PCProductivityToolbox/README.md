# PC效率工具箱 v1.0.0

## 版本信息

- **版本号**: 1.0.0
- **发布日期**: 2026-02-19
- **适用平台**: Windows 10 / Windows 11 (64位)

## 功能概览

### 桌面置顶计时器
- ✅ 倒计时模式
- ✅ 番茄钟模式
- ✅ 正向计时（秒表）模式
- ✅ 外观自定义（颜色、透明度、字体大小）
- ✅ 声音和闪烁提示

### 桌面待办事项
- ✅ 任务管理（添加、编辑、删除）
- ✅ 完成度评分（0-10分）
- ✅ 双显示模式（置顶/桌面固定）
- ✅ 窗口锁定功能
- ✅ 操作日志记录
- ✅ 日志导出（JSON/CSV）

### 系统功能
- ✅ 系统托盘集成
- ✅ 最小化到托盘
- ✅ 数据自动保存

## 使用方法

1. 双击 `PCProductivityToolbox.exe` 启动程序
2. 选择需要使用的工具模块
3. 根据界面提示进行操作

程序数据存储在：
```
C:\Users\<用户名>\AppData\Local\PCProductivityToolbox\
```
