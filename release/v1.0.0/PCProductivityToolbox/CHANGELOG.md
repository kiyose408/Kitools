# 更新日志

## [v1.0.0] - 2026-02-19

### 新增功能

#### 桌面置顶计时器
- 倒计时模式：支持设置时/分/秒进行倒计时
- 番茄钟模式：支持自定义工作时长、休息时长、循环次数
- 正向计时模式：无上限计时，适合记录工作时长
- 外观设置：窗口大小、字体大小、背景颜色、文字颜色、透明度
- 提示功能：声音提示、闪烁提示

#### 桌面待办事项
- 任务管理：添加、编辑、删除任务
- 完成标记：复选框标记完成状态
- 完成度评分：滑动条评分（0-10分）
- 显示模式：置顶模式、桌面固定模式
- 窗口控制：拖动、锁定位置
- 外观设置：背景颜色、透明度、字体
- 日志功能：自动记录操作、支持JSON/CSV导出

#### 系统功能
- 系统托盘集成
- 最小化到托盘运行
- 数据自动持久化

### 技术特性
- 开发语言：C++17
- GUI框架：Qt 6.9.0
- 构建系统：CMake 3.16+
- 架构设计：模块化、MVC模式
