## 一、需求背景

### 1.1 问题分析

在日常办公和学习场景中，用户普遍面临以下效率痛点：

| 痛点 | 描述 | 影响 |
|------|------|------|
| 时间管理困难 | 缺乏有效的时间追踪和提醒手段 | 工作效率低下 |
| 任务碎片化 | 待办事项分散在各处，难以统一管理 | 重要事项遗漏 |
| 信息记录零散 | 临时想法、笔记无处安放 | 灵感丢失 |
| 专注力不足 | 缺乏专注工具，容易分心 | 工作质量下降 |
| 数据不集中 | 效率数据分散，难以分析改进 | 无法持续优化 |

### 1.2 需求定位

基于上述痛点分析，本项目定位为：

**"轻量级、模块化、桌面置顶"** 的效率工具集合

核心设计目标：

- **桌面置顶**：关键信息始终可见，无需切换窗口
- **模块化设计**：功能独立，按需使用，互不干扰
- **轻量运行**：低资源占用，快速启动，无后台服务
- **数据本地化**：隐私保护，数据完全由用户掌控

### 1.3 目标用户

| 用户群体 | 典型场景 |
|---------|---------|
| 程序员 | 番茄工作法、任务追踪、代码片段、专注编程 |
| 学生 | 学习计时、作业管理、笔记记录、考试复习 |
| 自由职业者 | 时间记录、项目管理、灵感捕捉、效率统计 |
| 办公人员 | 会议提醒、任务清单、便签记录、时间规划 |

## 四、设计理念

### 4.1 设计模式应用

#### 单例模式 (Singleton)

用于全局唯一的管理器：

```cpp
class TaskManager : public QObject {
public:
    static TaskManager* instance() {
        static TaskManager instance;
        return &instance;
    }
private:
    TaskManager() = default;
};
```

应用位置：
- `SettingsManager` - 计时器设置管理
- `TaskManager` - 任务数据管理
- `LogManager` - 日志管理
- `NotesManager` - 便签数据管理
- `NotesReminder` - 便签提醒管理

#### 观察者模式 (Observer)

基于Qt信号槽机制实现数据变更通知：

```cpp
connect(taskManager, &TaskManager::taskAdded, 
        widget, &TodoWidget::onTaskAdded);
```

#### MVC模式

| 角色 | 组件 | 职责 |
|------|------|------|
| Model | TaskManager, NotesManager | 数据管理和业务逻辑 |
| View | DesktopTodoWidget, NotesItemWidget | 界面展示 |
| Controller | TodoController, NotesController | 协调Model和View |

### 4.2 数据持久化

| 数据类型 | 存储格式 | 存储位置 |
|---------|---------|---------|
| 计时器设置 | INI | `%AppData%/Local/PCProductivityToolbox/settings.ini` |
| 任务数据 | JSON | `%AppData%/Local/PCProductivityToolbox/tasks.json` |
| 日志数据 | JSON | `%AppData%/Local/PCProductivityToolbox/logs.json` |
| 便签数据 | JSON | `%AppData%/Local/PCProductivityToolbox/notes.json` |

### 4.3 平台适配

针对Windows平台的特殊处理：

```cpp
#ifdef Q_OS_WIN
#include <windows.h>
// 使用Win32 API实现窗口置顶
HWND hwnd = reinterpret_cast<HWND>(winId());
SetWindowPos(hwnd, HWND_TOPMOST, 0, 0, 0, 0, 
             SWP_NOMOVE | SWP_NOSIZE | SWP_NOACTIVATE);
#endif
```

## 快速开始

- Windows 10/11 (64位)
- Qt 6.9.0 或更高版本
- CMake 3.16+
- C++17 兼容编译器

### 构建步骤

```bash
# 克隆仓库
git clone https://github.com/your-repo/kitools.git
cd kitools

# 创建构建目录
mkdir build && cd build

# 配置项目
cmake ..

# 构建
```
