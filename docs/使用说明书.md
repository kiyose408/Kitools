## 1. 软件简介

PC效率工具箱是一款专为Windows桌面用户设计的效率提升工具软件。本软件提供多种实用工具，帮助用户更好地管理时间、提高工作效率。

### 当前版本包含的工具

| 工具名称 | 功能描述 |
|---------|---------|
| 桌面置顶计时器 | 支持倒计时、番茄钟、正向计时三种模式的置顶计时器 |
| 桌面待办事项 | （开发中）桌面待办列表管理工具 |

## 3. 安装与启动

## 5. 桌面置顶计时器

桌面置顶计时器是本软件的核心功能，提供三种计时模式，适用于不同的使用场景。

### 进入计时器
1. 在主界面点击"桌面置顶计时器"卡片
2. 进入计时器设置界面
3. 同时会显示一个置顶的计时窗口

### 5.1 倒计时模式

**适用场景**：需要设定固定时间进行倒计时的场景，如：
- 烹饪计时
- 运动休息
- 会议提醒
- 学习时段

**使用方法**：
1. 选择"倒计时"标签页
2. 设置时、分、秒数值
3. 点击"开始"按钮启动计时
4. 计时过程中可点击"暂停"暂停计时
5. 点击"停止"可终止计时并重置

**界面说明**：
```
┌─────────────────────────────────────┐
│ [倒计时] [番茄钟] [正向计时]        │
├─────────────────────────────────────┤
│  时: [ 0 ]  分: [25]  秒: [ 0 ]     │
└─────────────────────────────────────┘
```

### 5.2 番茄钟模式

**适用场景**：采用番茄工作法进行时间管理，适合：
- 专注工作
- 学习复习
- 项目开发
- 写作创作

**使用方法**：
1. 选择"番茄钟"标签页
2. 设置工作时长（默认25分钟）
3. 设置休息时长（默认5分钟）
4. 设置循环次数（默认4次）
5. 点击"开始"启动番茄钟

**工作流程**：
```
工作(25分钟) → 休息(5分钟) → 工作(25分钟) → 休息(5分钟) → ...
```

**状态显示**：
- 置顶窗口会显示当前状态："工作中"（红色）或"休息中"（绿色）
- 完成所有循环后自动停止

**界面说明**：
```
┌─────────────────────────────────────┐
│ [倒计时] [番茄钟] [正向计时]        │
├─────────────────────────────────────┤
│ 工作时长(分): [25]  休息时长(分): [5]│
│ 循环次数: [ 4 ]                     │
└─────────────────────────────────────┘
```

### 5.3 正向计时模式

**适用场景**：需要记录时长的场景，如：
- 记录工作时长
- 运动计时
- 会议时长统计
- 活动计时

**使用方法**：
1. 选择"正向计时"标签页
2. 点击"开始"开始计时（从00:00开始）
3. 计时过程中可点击"暂停"暂停计时
4. 点击"停止"终止计时并重置为00:00

**特点**：
- 无时间上限，可持续计时
- 状态显示为"计时中"（蓝色）
- 适合需要统计时长的场景

### 控制按钮说明

| 按钮 | 功能 | 快捷提示 |
|------|------|---------|
| ▶ 开始 | 启动计时器 | 计时开始后按钮禁用 |
| ⏸ 暂停 | 暂停当前计时 | 暂停后可点击开始继续 |
| ⏹ 停止 | 停止并重置计时 | 清零所有计时数据 |
| ← 返回 | 返回主界面 | 计时不会停止，继续后台运行 |

## 6. 外观设置

您可以根据个人喜好自定义置顶计时窗口的外观。

### 窗口尺寸
- **窗口宽度**：100-500像素
- **窗口高度**：50-300像素

### 字体设置
- **字体大小**：16-72像素，通过滑块调节

### 颜色设置
- **背景颜色**：点击颜色按钮选择背景色
- **文字颜色**：点击颜色按钮选择文字颜色

### 透明度设置
- **背景透明度**：0-255，数值越小越透明
- **文字透明度**：0-255，数值越小越透明

### 设置生效
外观设置更改后会立即应用到置顶窗口，无需重启软件。

## 7. 提示设置

计时结束时，软件可提供以下提示方式：

### 声音提示
- 勾选"启用声音提示"后，计时结束时播放系统提示音
- 取消勾选则静音

### 闪烁提示
- 勾选"启用闪烁提示"后，计时结束时置顶窗口闪烁
- 闪烁持续直到用户点击停止或开始新的计时

## 8. 系统托盘功能

### 最小化到托盘
- 点击主窗口的关闭按钮（×）时，软件不会退出
- 主窗口会隐藏到系统托盘，计时任务继续运行
- 首次最小化时会显示提示气泡

### 托盘图标操作

| 操作 | 功能 |
|------|------|
| 单击/双击托盘图标 | 显示主窗口 |
| 右键托盘图标 | 显示托盘菜单 |

### 托盘菜单

| 菜单项 | 功能 |
|--------|------|
| 显示主窗口 | 恢复显示主窗口 |
| 退出 | 完全退出软件 |

### 完全退出软件
如需完全退出软件，请通过以下方式之一：
1. 右键托盘图标 → 点击"退出"
2. 显示主窗口 → 再次点击关闭按钮（如果未在计时）

## 9. 常见问题

### Q1: 为什么关闭窗口后软件还在运行？
**A**: 这是设计行为。关闭窗口会将软件最小化到系统托盘，计时任务会继续运行，避免误关闭导致计时中断。如需完全退出，请通过托盘菜单的"退出"选项。

### Q2: 如何移动置顶计时窗口？
**A**: 鼠标左键按住置顶窗口并拖动即可移动位置。窗口位置在当前计时周期内会保持。

### Q3: 切换到其他工具后计时会停止吗？
**A**: 不会。点击"返回"按钮只是返回主界面，当前计时会继续在后台运行。置顶窗口也会保持显示。

### Q4: 设置会保存吗？
**A**: 是的。您的时间设置、外观设置等都会自动保存，下次启动软件时会自动恢复。

### Q5: 番茄钟的工作和休息时间如何区分？
**A**: 置顶窗口会显示当前状态：
- "工作中" - 红色文字
- "休息中" - 绿色文字
- "计时中" - 蓝文字（正向计时模式）
- "就绪" - 灰色文字（未开始状态）

### Q6: 正向计时模式有时间限制吗？
**A**: 没有时间限制，可以持续计时直到您手动停止。显示格式会根据时长自动调整：
- 1小时内：显示为 `分:秒`（如 25:30）
- 超过1小时：显示为 `时:分:秒`（如 1:25:30）

### Q7: 为什么我的置顶窗口不显示？
**A**: 请检查：
1. 是否已点击"开始"按钮启动计时
2. 置顶窗口是否被其他全屏窗口遮挡
3. 尝试点击托盘图标恢复主窗口，然后重新进入计时器
