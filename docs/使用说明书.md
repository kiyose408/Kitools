## 1. 软件简介

PC效率工具箱是一款专为Windows桌面用户设计的效率提升工具软件。本软件采用模块化设计，提供多种实用工具，帮助用户更好地管理时间、提高工作效率。

### 当前版本包含的工具

| 工具名称 | 功能描述 |
|---------|---------|
| 桌面置顶计时器 | 支持倒计时、番茄钟、正向计时三种模式的置顶计时器 |
| 桌面待办事项 | 支持任务管理、完成度评分、日志记录的桌面待办工具 |
| 桌面便签 | 支持Markdown、提醒功能的独立窗口便签工具 |

### 软件特色

- 🎯 **桌面置顶** - 工具窗口可始终显示在最前端
- 📌 **窗口固定** - 支持将窗口固定到桌面特定位置
- 🎨 **外观自定义** - 支持自定义颜色、深色模式、字体等
- 💾 **数据持久化** - 自动保存设置和数据
- 📊 **日志记录** - 自动记录操作历史，支持导出
- 📝 **Markdown支持** - 便签支持Markdown格式渲染

## 5. 桌面置顶计时器

桌面置顶计时器是本软件的核心功能之一，提供三种计时模式，适用于不同的使用场景。

### 进入计时器
1. 在主界面点击"桌面置顶计时器"卡片
2. 进入计时器设置界面
3. 同时会显示一个置顶的计时窗口

### 5.1 倒计时模式

**适用场景**：
- 烹饪计时
- 运动休息
- 会议提醒
- 学习时段

**使用方法**：
1. 选择"倒计时"标签页
2. 设置时、分、秒数值
3. 点击"开始"按钮启动计时
4. 计时过程中可点击"暂停"暂停计时
5. 点击"停止"可终止计时并重置

**界面说明**：
```
┌─────────────────────────────────────┐
│ [倒计时] [番茄钟] [正向计时]        │
├─────────────────────────────────────┤
│  时: [ 0 ]  分: [25]  秒: [ 0 ]     │
└─────────────────────────────────────┘
```

### 5.2 番茄钟模式

**适用场景**：
- 专注工作
- 学习复习
- 项目开发
- 写作创作

**使用方法**：
1. 选择"番茄钟"标签页
2. 设置工作时长（默认25分钟）
3. 设置休息时长（默认5分钟）
4. 设置循环次数（默认4次）
5. 点击"开始"启动番茄钟

**工作流程**：
```
工作(25分钟) → 休息(5分钟) → 工作(25分钟) → 休息(5分钟) → ...
```

**状态显示**：
- 置顶窗口会显示当前状态："工作中"（红色）或"休息中"（绿色）
- 完成所有循环后自动停止

### 5.3 正向计时模式

**适用场景**：
- 记录工作时长
- 运动计时
- 会议时长统计
- 活动计时

**使用方法**：
1. 选择"正向计时"标签页
2. 点击"开始"开始计时（从00:00开始）
3. 计时过程中可点击"暂停"暂停计时
4. 点击"停止"终止计时并重置为00:00

**特点**：
- 无时间上限，可持续计时
- 状态显示为"计时中"（蓝色）

### 5.4 控制按钮说明

| 按钮 | 功能 | 说明 |
|------|------|------|
| ▶ 开始 | 启动计时器 | 计时开始后按钮禁用 |
| ⏸ 暂停 | 暂停当前计时 | 暂停后可点击开始继续 |
| ⏹ 停止 | 停止并重置计时 | 清零所有计时数据 |
| ← 返回 | 返回主界面 | 计时不会停止，继续后台运行 |

### 5.5 外观设置

您可以根据个人喜好自定义置顶计时窗口的外观。

| 设置项 | 范围 | 说明 |
|--------|------|------|
| 窗口宽度 | 100-500像素 | 调整窗口宽度 |
| 窗口高度 | 50-300像素 | 调整窗口高度 |
| 字体大小 | 16-72像素 | 调整时间显示字体大小 |
| 背景颜色 | 任意颜色 | 点击颜色按钮选择 |
| 文字颜色 | 任意颜色 | 点击颜色按钮选择 |
| 背景透明度 | 0-255 | 0为完全透明，255为完全不透明 |
| 文字透明度 | 0-255 | 调整文字显示透明度 |

### 5.6 提示设置

| 设置项 | 说明 |
|--------|------|
| 启用声音提示 | 计时结束时播放系统提示音 |
| 启用闪烁提示 | 计时结束时置顶窗口闪烁提醒 |

## 6. 桌面待办事项

桌面待办事项是一个功能完善的任务管理工具，支持任务的创建、编辑、完成标记、评分等功能。

### 进入待办事项
1. 在主界面点击"桌面待办事项"卡片
2. 进入待办事项设置界面
3. 同时会显示一个待办事项窗口

### 6.1 任务管理

#### 添加任务
1. 在输入框中输入任务描述
2. 按回车键或点击"+"按钮添加任务
3. 任务会自动添加到列表顶部

#### 编辑任务
1. 点击任务项右侧的"✏"按钮
2. 在输入框中修改任务描述
3. 按回车键保存修改

#### 删除任务
- 点击任务项右侧的"×"按钮删除任务

#### 标记完成
- 点击任务左侧的复选框标记任务完成/未完成
- 完成的任务会显示删除线效果

#### 完成度评分
- 完成任务后会出现滑动条
- 拖动滑块设置完成度评分（0-10分）
- 松开滑块时自动记录评分

### 6.2 显示模式

| 模式 | 说明 | 特点 |
|------|------|------|
| 置顶模式 | 窗口始终保持在所有应用最顶层 | 适合需要随时查看的场景 |
| 桌面固定模式 | 窗口处于所有应用最底层，固定在右上角 | 适合作为桌面背景元素 |

**切换方式**：
- 在设置面板中选择显示模式
- 点击待办窗口上的"置顶/固定"按钮快速切换

### 6.3 窗口控制

#### 拖动窗口
- 鼠标左键按住窗口任意位置拖动

#### 锁定窗口
- 点击左上角的"📌"按钮锁定窗口位置
- 锁定后窗口无法拖动
- 再次点击解锁

#### 清理已完成任务
- 点击右上角的"清理"按钮
- 一键清除所有已完成的任务

### 6.4 外观设置

| 设置项 | 说明 |
|--------|------|
| 背景颜色 | 设置待办窗口背景颜色（深色模式下无效） |
| 深色模式 | 一键切换深色/浅色主题 |
| 字体 | 选择显示字体 |

### 6.5 日志功能

#### 自动记录
系统会自动记录以下操作：
- 创建任务
- 完成任务
- 完成度/自评
- 删除任务
- 编辑任务

#### 导出日志
- **JSON格式**：适合数据备份和程序处理
- **CSV格式**：适合用Excel查看和分析

#### 重置日志
- 点击"重置日志"按钮清空所有日志记录
- 清空前会有确认提示

## 7. 桌面便签

桌面便签是一个灵活的笔记工具，每个便签都是独立窗口，可以自由拖动到桌面任意位置，实现便签墙效果。

### 进入便签
1. 在主界面点击"桌面便签"卡片
2. 进入便签管理界面

### 7.1 创建便签

1. 点击"+ 新建便签"按钮
2. 自动创建一个新的便签窗口
3. 新便签自动进入编辑模式，可直接输入内容

### 7.2 编辑便签

#### 进入编辑模式
- 点击便签右上角的"✏"按钮
- 新建的便签自动进入编辑模式

#### 编辑内容
| 字段 | 说明 |
|------|------|
| 标题 | 可选，不填写则自动提取内容首行 |
| 颜色 | 五种预设颜色可选 |
| 提醒 | 勾选后设置提醒时间 |
| 内容 | 支持Markdown格式的文本内容 |

#### 保存与取消
- 点击"保存"按钮保存修改
- 点击"取消"按钮放弃修改

### 7.3 颜色分类

| 颜色 | 适用场景 |
|------|---------|
| 🟡 黄色 | 默认/普通笔记 |
| 🟢 绿色 | 工作/代码 |
| 🔵 蓝色 | 学习/资料 |
| 🩷 粉色 | 生活/购物 |
| 🟣 紫色 | 重要/紧急 |

### 7.4 提醒功能

#### 设置提醒
1. 进入编辑模式
2. 勾选"提醒"复选框
3. 设置提醒日期和时间
4. 保存便签

#### 提醒触发
- 系统托盘弹出通知气泡
- 便签窗口正反色交替闪烁
- 便签自动置顶显示

### 7.5 Markdown支持

便签内容支持以下Markdown语法：

| 语法 | 效果 | 示例 |

| `### 标题` | 三级标题 | `### 详细说明` |

**代码块示例**：

## 8. 系统托盘功能

### 最小化到托盘
- 点击主窗口的关闭按钮（×）时，软件不会退出
- 主窗口会隐藏到系统托盘，计时任务继续运行
- 首次最小化时会显示提示气泡

### 托盘图标操作

| 操作 | 功能 |
|------|------|
| 单击/双击托盘图标 | 显示主窗口 |
| 右键托盘图标 | 显示托盘菜单 |

### 托盘菜单

| 菜单项 | 功能 |
|--------|------|
| 显示主窗口 | 恢复显示主窗口 |
| 退出 | 完全退出软件 |

### 完全退出软件
如需完全退出软件，请通过以下方式之一：
1. 右键托盘图标 → 点击"退出"
2. 显示主窗口 → 再次点击关闭按钮（如果未在计时）

## 10. 常见问题

### Q1: 为什么关闭窗口后软件还在运行？
**A**: 这是设计行为。关闭窗口会将软件最小化到系统托盘，计时任务会继续运行，避免误关闭导致计时中断。如需完全退出，请通过托盘菜单的"退出"选项。

### Q2: 如何移动置顶窗口？
**A**: 鼠标左键按住窗口并拖动即可移动位置。

### Q3: 切换到其他工具后计时会停止吗？
**A**: 不会。点击"返回"按钮只是返回主界面，当前计时会继续在后台运行。

### Q4: 设置会保存吗？
**A**: 是的。您的时间设置、外观设置等都会自动保存，下次启动软件时会自动恢复。

### Q5: 番茄钟的工作和休息时间如何区分？
**A**: 置顶窗口会显示当前状态：
- "工作中" - 红色文字
- "休息中" - 绿色文字
- "计时中" - 蓝色文字（正向计时模式）
- "就绪" - 灰色文字（未开始状态）

### Q6: 待办事项的完成度评分有什么用？
**A**: 完成度评分帮助您评估任务完成质量，所有评分都会记录在日志中，可用于后续分析工作效率。

### Q7: 为什么我的置顶窗口不显示？
**A**: 请检查：
1. 是否已点击"开始"按钮启动计时
2. 置顶窗口是否被其他全屏窗口遮挡
3. 尝试点击托盘图标恢复主窗口

### Q8: 如何让待办窗口固定在桌面上不被其他窗口遮挡？
**A**: 切换到"桌面固定模式"，窗口会固定在桌面右上角，始终显示在所有窗口的最底层。

### Q9: 日志数据会占用很多空间吗？
**A**: 日志数据以JSON格式存储，文件很小。如果日志过多，可以使用"重置日志"功能清空。

### Q10: 便签可以创建多少个？
**A**: 没有数量限制，您可以根据需要创建任意数量的便签。

### Q11: 便签的提醒没有触发怎么办？
**A**: 请检查：
1. 确认已勾选"提醒"并设置了正确的时间
2. 确认软件正在运行（最小化到托盘也算）
3. 如果软件重启，已过期的提醒不会再次触发

### Q12: Markdown语法不生效怎么办？
**A**: 请确保：
1. 语法格式正确，如 `**粗体**` 前后都要有星号
2. 代码块使用三个反引号包裹
3. 标题的 `#` 后面要有空格
