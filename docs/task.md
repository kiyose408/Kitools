#### T023 - 开机自启动功能

| 项目   | 内容           |
| ---- | ------------ |
| 任务ID | T023         |
| 任务名称 | 实现开机自启动系统     |
| 任务类型 | 核心功能         |
| 优先级  | P0           |
| 预估工时 | 2天           |
| 状态   | ✅ 已完成          |

**需求背景**:

作为效率工具，用户希望应用能够在开机时自动启动，实现无感记录操作习惯和统计效率。同时剪贴板和时间追踪器模块也需要支持独立控制是否自启动。

**任务描述**:

- **全局应用自启动**
  - 主界面首页添加"开机自动启动"开关
  - 通过Windows注册表实现自启动（HKEY_CURRENT_USER）
  - AutoStartManager单例类管理注册表操作
  - 用户选择实时生效并持久化保存

- **模块级独立自启动**
  - 剪贴板模块："启动时自动开始监控"选项
  - 时间追踪器模块："开机自动启动追踪"选项
  - 每个模块可独立开关，默认启用
  - 配置通过SettingsManager持久化到QSettings

- **配置持久化机制**
  - 新增6个配置接口到SettingsManager
  - autostart/enabled：全局自启动开关
  - autostart/clipboardAutoStart：剪贴板自动监控
  - autostart/timeTrackerAutoStart：时间追踪器自动追踪
  - 应用重启后保持用户选择

- **AutoStartManager核心组件**
  - 单例模式设计，全局唯一实例
  - isAutoStartEnabled()检查当前状态
  - setAutoStartEnabled()设置自启/禁用
  - checkRegistryAutoStart()读取注册表
  - writeToRegistry()写入/删除注册表项
