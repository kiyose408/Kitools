## 1. 项目概述

### 1.1 项目定位

PC效率工具箱是一个模块化的桌面效率工具集合，采用插件化架构设计，每个功能模块独立开发、独立运行，通过统一的主框架进行管理。

### 1.2 设计目标

| 目标 | 描述 |
|------|------|
| 模块化 | 各功能模块独立，便于扩展和维护 |
| 轻量化 | 最小化资源占用，快速启动 |
| 易用性 | 简洁直观的用户界面 |
| 可扩展 | 支持快速添加新的效率工具模块 |

### 1.3 版本信息

| 属性 | 值 |
|------|-----|
| 项目名称 | PCProductivityToolbox |
| 版本号 | 1.1.0 |
| 开发语言 | C++17 |
| GUI框架 | Qt 6.9.0 |
| 构建系统 | CMake 3.16+ |
| 目标平台 | Windows 10/11 |

## 7. 设计模式应用

### 7.1 单例模式 (Singleton)

**应用场景**：全局唯一的管理器

**实现示例**：
```cpp
class TaskManager : public QObject {
public:
    static TaskManager* instance() {
        static TaskManager instance;
        return &instance;
    }
private:
    TaskManager() = default;
    TaskManager(const TaskManager&) = delete;
    TaskManager& operator=(const TaskManager&) = delete;
};
```

**使用位置**：
- `SettingsManager` - 计时器设置管理
- `TaskManager` - 任务数据管理
- `LogManager` - 日志管理
- `NotesManager` - 便签数据管理
- `NotesReminder` - 便签提醒管理

### 7.2 观察者模式 (Observer)

**应用场景**：Qt信号槽机制

**实现方式**：
```cpp
// 数据变更通知
connect(taskManager, &TaskManager::taskAdded, 
        widget, &TodoWidget::onTaskAdded);

// 提醒触发
connect(reminder, &NotesReminder::reminderTriggered,
        widget, &NotesWidget::onReminderTriggered);
```

### 7.3 MVC模式

**应用场景**：模块架构

| 角色 | 组件 | 职责 |
|------|------|------|
| Model | TaskManager, NotesManager | 数据管理和业务逻辑 |
| View | DesktopTodoWidget, NotesItemWidget | 界面展示 |
| Controller | TodoController, NotesController | 协调Model和View |

### 7.4 组合模式 (Composite)

**应用场景**：任务列表组件、便签集合

```cpp
// TaskItemWidget 组合成任务列表
QVBoxLayout *m_taskLayout;
for (const TaskData &task : tasks) {
    TaskItemWidget *widget = new TaskItemWidget(task);
    m_taskLayout->insertWidget(0, widget);
}

// NotesItemWidget 独立窗口组合
QMap<int, NotesItemWidget*> m_noteWidgets;
for (const NoteData &note : notes) {
    NotesItemWidget *widget = new NotesItemWidget(note);
    m_noteWidgets[note.id] = widget;
}
```

## 8. 扩展指南

### 8.1 添加新模块步骤

1. **创建模块目录**
   ```
   src/modules/newmodule/
   ├── newmodulecontroller.h/cpp
   ├── newmodulewidget.h/cpp
   ├── newmoduleitemwidget.h/cpp
   ├── newmodulesettingspanel.h/cpp
   ├── newmodulemanager.h/cpp
   └── newmoduledatatypes.h
   ```

2. **实现控制器接口**
   ```cpp
   class NewModuleController : public QObject {
   public:
       QWidget* settingsPanel();  // 返回设置面板
       QWidget* mainWidget();     // 返回主界面组件
   };
   ```

3. **注册到主窗口**
   ```cpp
   // mainwindow.cpp
   m_newModuleController = new NewModuleController(this);
   m_newModulePanel = m_newModuleController->settingsPanel();
   m_stackedWidget->addWidget(m_newModulePanel);
   ```

4. **添加入口卡片**
   ```cpp
   QPushButton *newModuleBtn = new QPushButton("🔧 新工具");
   connect(newModuleBtn, &QPushButton::clicked, this, &MainWindow::onNewModuleClicked);
   ```

5. **更新CMakeLists.txt**
   ```cmake
   set(SOURCES
       ...
       src/modules/newmodule/newmodulecontroller.cpp
       ...
   )
   ```

### 8.2 模块开发规范
